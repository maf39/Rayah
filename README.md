# RAYAH
تطبيق ويب تقدمي عربي لإدارة العادات والأهداف.

- لا يحتاج build step؛ الملفات ثابتة.
- البيانات تحفظ محلياً في المتصفح عبر localStorage.
- لا يوجد حساب مستخدم أو مزامنة سحابية.
- التثبيت متاح من قائمة مشاركة Safari على iPhone (إضافة إلى الشاشة الرئيسية).
- بعض إمكانات iOS الأصلية مثل Apple Health وحظر التطبيقات وودجات النظام وSiri غير متاحة كتطبيق ويب.
